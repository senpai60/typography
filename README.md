# 🎨 Typography CSS (CDN)

Reusable typography stylesheet for consistent text styling across projects.

---

## 🚀 CDN Link

```html
https://cdn.jsdelivr.net/gh/senpai60/typography@v1/typography-v1.css
```

---

## 🔗 Usage

Add this `<link>` tag inside your HTML `<head>`:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/senpai60/typography@v1/typography-v1.css">
```

## 📦 Version

* Current version: `v1`

---

## 💡 Notes

* Make sure to use the correct version (`@v1`) to avoid breaking changes.
* If updates don’t reflect, try a hard refresh (`Ctrl + Shift + R`).

---

## ⚡ Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Typography Demo</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/senpai60/typography@v1/typography-v1.css">
</head>
<body>
  <h1>Hello World</h1>
  <p>This text is styled using Typography CSS.</p>
</body>
</html>
```
